# Читання, запис і запити до документів

- Читає та змінює крапкові шляхи полів і селектори з оболонки, тож поля можна міняти без ручного редагування YAML.
- Конвертує між кодуваннями (YAML/JSON), валідує за вбудованою схемою та видаляє поля, надлишкові через include.
- Прогріває та очищає HTTP-кеш розв’язання include.
- Запускає інтерактивний майстер першого налаштування для користувацької конфігурації.
